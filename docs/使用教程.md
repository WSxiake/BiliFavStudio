# BiliFav Studio 使用教程

先完成收藏夹整理或搬运，再按需要查看浏览筛选、标签、统计和设置。**「保存整理」只存到本机；「提交改动」才把整理结果同步到 B 站。搬运会直接写入目标收藏夹。**

## 一、收藏夹整理

### 1. 登录并打开收藏夹

1. 打开桌面程序。首次出现配色窗口时，选一个喜欢的主题，点「就用这个」。
2. 在「菜单」点击头像或昵称进入登录页，用 B 站手机 App 扫码，并在手机上确认。二维码过期时点「换一张」。
3. 回到「菜单」核对账号，点底部「浏览」，再点左上角「收藏夹」，选择自己的收藏夹。
4. 首次打开需等完整列表读完再整理；已有的完整缓存可以直接打开，提示条会标明缓存时间。

### 2. 调整视频顺序

点「开始整理」，按钮变成「保存整理」，编辑工具出现。拖动卡片，根据落点提示调整位置；多选后可整批拖动。预览时按住卡片约 0.4 秒再拖，也会自动进入整理模式。

同一个一键排序按钮依次切换：**升序 → 降序 → 还原到按这个按钮之前的顺序**。换一个排序维度，会重新记录还原起点。

### 3. 批量选择

点「多选」后，点击卡片可选中或取消；Shift + 点击可连续选择，Ctrl + Shift + 点击可取消一段。「全选本页」只处理当前页中符合筛选条件的视频，再点一次会取消这些视频的选择；其他页及筛选外的选择保留。需要清空所有选择时点「取消选择」。退出多选也会清空选择。

### 4. 添加、导入与删除

- **添加视频**：输入 BV 号、av 号或视频链接，也可切到「搜标题」。一次最多输入 50 个；加入当前清单后仍是待提交状态。
- **导入**：选择 CSV、TXT、MD 文件，或拖到卡片区。软件按文件中出现的顺序识别编号和链接，已有视频会跳过；不会按文件重排已有视频，也不会完整恢复标签等资料。
- **删除**：点击卡片垃圾桶先标为待删除，可在提交前取消。已新增但未提交的视频可以直接取消追加。
- **一键标记失效项**：按界面后续选择处理，若标成待删除，仍需提交才会从线上移出。它与收藏夹菜单中的「清理失效内容」不是同一种操作。

### 5. 保存并提交

| 动作 | 结果 |
|---|---|
| 草稿自动保存 | 有改动后延迟写入本机，底部显示保存状态 |
| Ctrl+S 快捷保存（默认键位） | 立即保存本机草稿，保持整理模式、当前页与选择，可继续操作 |
| 保存整理 | 等本机写入成功后回到预览，不上传这份改动 |
| 提交改动 | 在整理模式中确认后，执行线上删除、添加和排序 |

保存失败时，软件会保留整理状态并提示重试。先保留窗口，重新按快捷保存或点「保存整理」，成功后再退出。快捷保存可在「菜单 → 快捷键」改键。重新打开收藏夹时，草稿只有与线上条目能够对应才会恢复；若线上内容已改变，不应把旧草稿当作有效备份。

草稿打包在后台执行；保存状态显示成功后才表示本机文件已写入。后台处理不可用时软件自动回退保存。设置按变化项写入；写入失败会提示并保留待保存设置，恢复连接或继续修改后重试。

提交前检查确认框里的增删和移动数量。提交按先删除、再添加、最后排序执行，在顶栏「任务」查看进度。任务中断不等于全部撤销，已完成部分会留在线上；刷新核对实际结果后再决定下一步。

### 6. 撤销、还原和回滚

- **撤销一步／重做一步**：在整理模式中恢复当前收藏夹的顺序、待删除标记、新增视频、自建标签及贴标、页锁与分页设置。批量删除或贴标可整批撤回。默认 Ctrl+Z／Ctrl+Y，默认重做也支持 Ctrl+Shift+Z。最多保留 60 步；历史随本机草稿保存，大清单保存时会优先保留最近历史。撤销后再做新操作会清空重做分支。线上内容或原始顺序变动后，旧草稿及历史不再套用；已经提交、直接跨夹操作、账号/外观设置、收藏夹列表排列不属于这份整理历史。
- **全部还原**：恢复加载时的清单顺序并清除增删标记，保留本机标签；这一步本身也可以撤销。它不是重新下载线上数据。
- **回滚提交**：有可用记录时显示，只恢复上次提交前的顺序，不恢复那次移出的收藏，也不能撤回直接跨夹操作。

### 7. 跨收藏夹复制、粘贴与移动

不能把所有操作都理解为「最后一起提交」：

| 操作 | 是否直接写入 B 站 |
|---|---|
| 整理页里的普通排序、待删除、待新增 | 否，需要提交改动 |
| 右键「直接复制到其他收藏夹」 | 是，加入目标夹末尾，保留源夹内容 |
| 右键「直接移到其他收藏夹」 | 是，加入目标夹末尾，并移出源夹中对应的成功条目 |
| 拖到左侧另一个收藏夹 | 是，复制到目标夹，源夹内容保留 |
| Ctrl+C 后到另一收藏夹 Ctrl+V | 否，在目标夹先变成待新增，需要提交 |
| 「搬运」页确认开始 | 是，按任务进度逐步写入 |
| 收藏夹设置、清理失效内容、删除收藏夹 | 按各自确认流程执行，不等整理页统一提交 |

「复制卡片」与「复制视频链接」不同：前者用于软件内粘贴，后者用于粘到聊天或文档。Ctrl+X 会在源清单产生待删除标记，跨夹粘贴会在目标清单产生待新增；不要把两份本地改动当成一次线上原子移动。想直接在线上移动时，使用明确标注的「直接移到其他收藏夹」。

卡片右键菜单分为「本机标签」「本地整理」「直接写入 B 站」「链接与打开」几组。复制条目后，在目标卡片上选择「粘贴到此卡前」或「粘贴到此卡后」；直接按 Ctrl+V 放在当前页开头，平铺时放到末尾。同夹粘贴只移动，不产生重复视频；同夹剪切后粘贴也会取消这批条目的待删除标记。跨夹粘贴先是待新增，仍需提交。目标页锁定时先解锁。预览中剪切、粘贴或发送到某页会自动进入整理。

右键已选卡片处理已选整批；右键未选卡片只处理这张。直接跨夹移动会立即写入 B 站，源夹有未提交增删或排序时应先提交或还原，再执行直接移动；操作结束后重新读取源夹并建立新基线，不能用本地撤销恢复线上移除。

## 二、收藏夹搬运

已登录后，点击底部「搬运」。它用于把公开收藏夹的视频收藏到自己的目标收藏夹。

搬运页从上到下操作：

1. **源收藏夹**：输入公开收藏夹链接或 ID，点「读取」；也可以按 UP 主 UID 或昵称查找公开收藏夹。
2. **目标收藏夹**：选择自己账号下的收藏夹，也可以新建。核对源和目标名称。
3. **搬运选项**：按需求选择内容类型及抓取顺序；初次使用保留目标预扫描、跳过失效和默认请求间隔即可。
4. 点「开始搬运」，在确认框核对后开始。此时会逐步收藏到 B 站，无需另点「提交改动」。
5. 顶栏「任务」可查看进度、暂停、继续或停止。中断后在「菜单 → 任务记录」找到任务，使用条目提供的继续操作。

去重、失效内容和接口限速会影响结果及耗时。完成后到「浏览」核对目标收藏夹，必要时再整理顺序。

## 三、浏览、搜索与页目录

右上角显示「开始整理」时，就是预览模式。排序、导入、添加视频、提交等修改工具在此时收起。

切换收藏夹优先使用本机完整缓存，并标明缓存时间，不会因为缓存较旧就锁住整理等待联网。缓存提示里的「重新读一遍」强制刷新当前夹；收藏夹栏的刷新还会更新收藏夹列表。主动刷新时可以点「先使用缓存」继续本地整理，稍后到达的刷新结果不会覆盖当前修改；刷新失败也会恢复缓存。首次打开且无缓存时仍需等待完整读取。使用缓存整理后，提交前会核对线上基线；不一致时不执行写入，本地草稿保留，可先导出再刷新核对。

收藏夹右键可改名、改简介。保存时按钮显示进度；成功后直接更新软件各处标题，不会再等待完整列表刷新。失败时保留输入，可重试。

快速切换卡片时，标题、时长和本机标签立即显示；停留后再读取该视频的站内标签和 UP 资料，已缓存的资料直接复用。

详情中的「去 B 站看」与顶栏「浏览器」通过系统默认浏览器打开页面。

清空收藏夹栏的搜索后，可以拖动收藏夹条目调整列表排列。这个顺序只保存在软件里，不会修改 B 站网页或 App 上的收藏夹排列。

### 查找视频

- 搜索框按标题或 UP 主筛选；左侧收藏夹栏先查收藏夹名称和本地缓存中的视频标题 / UP 主，不会自动逐夹联网搜索。下方标明缓存覆盖数量和最早更新时间，缓存不代表最新状态；需要补查时点「在线补查」，可中途停止。在线查询每夹只取前 20 条命中。
- 筛选框内右侧的小按钮切换关键词筛选范围：「本页」（默认）只筛眼前这一页；输入关键词后，「本收藏夹」把整个收藏夹的命中视频一次全铺出来（翻页条收起）。关键词为空时仍保留分页。切换范围会保留输入的关键词。
- 日期框按**收藏时间**筛选，不是投稿时间；只填一端表示另一端不限。没有收藏时间的视频在日期筛选时不显示。
- 点击任意标签查看对应视频，可以选中多个标签取并集；再次点击取消该标签，点「全部」清除标签筛选。标签无论是否置顶都使用自己设置的颜色；置顶只影响显示优先级和排序。
- 分页依据完整清单的位置切分，筛选后不会把结果重新凑满每页。本页为空时，其他页仍可能有结果。

### 分页与视频详情

点「页目录」可快速翻页，并设置每页 20、30、50 条、自定义或无限平铺。按住页目录左边缘的细线拖动可调整宽度，页格随栏宽自动换列，宽度记在本机。页数超过一屏时在目录内部滚动，后面的页不会被截掉；拖着卡片或整页靠近目录上下边缘会自动滚动。锁页只限制直接向该页拖入或发送视频，并不冻结整页：全局排序、前面页面的增删仍可能改变页内内容。修改每页条数会影响原页号和页锁，按界面提示确认。点面板 × 或再次点「页目录」关闭面板。

点击视频卡片，视频详情会在左侧独立打开，可查看资料、链接和「我的标签」。详情与左侧收藏夹列表互相切换，右侧页目录可以单独打开或关闭。详情右侧的把手可以调宽度，× 只关闭详情；切到菜单时，详情和页目录都会自动收起。

拖动视频时，如果左侧栏已经打开，会自动显示收藏夹列表，方便把视频拖入另一个收藏夹；左侧栏原本收起时会保持收起。拖入其他收藏夹会直接添加到目标收藏夹，原收藏保留。多选模式下，可拖动已选卡片批量添加。

搜索结果较多或使用无限平铺时，只绘制屏幕附近的卡片；滚动可继续查看全部结果。全选、Shift 连选、复制和导出仍覆盖当前筛选的完整结果，不限于眼前已经画出的卡片。

## 四、本机标签

点「标签」打开管理窗口，先选择颜色、再输入名称并按回车创建。名称最多 5 个字。

给视频贴标签有两种常用方法：在卡片上点右键选择标签，或打开详情，在「我的标签」中点击标签。每个视频最多贴 5 个自己的标签；多选后右键，可以给这一批视频统一贴标签，已满上限的条目会跳过并提示。

标签按收藏夹分别保存。同一个视频在两个收藏夹里，可以有不同标签。标签只在本机使用，贴好后不用点「提交改动」。

标签管理里的两个容易混淆的功能：

- **复制到…**：只复制标签名称和颜色，不复制视频，也不复制视频与标签的对应关系。
- **一键同步站内标签**：读取视频在 B 站已有的标签，与自己的同名标签匹配后，在本机贴标；不是把自己的标签上传到 B 站。

置顶标签会优先显示在浏览页「全部」旁边；按住置顶标签后拖动，可以调整它们的显示顺序。置顶不改变标签自己的颜色。

## 五、时长与选择范围统计

底部有三组统计：

| 统计 | 计算范围 |
|---|---|
| 全部／筛选结果 | 当前清单中符合搜索、日期和标签条件的视频，跨所有页 |
| 本页 | 当前页实际符合筛选条件的视频 |
| 已选（跨页） | 整份清单中已选的视频，也包含其他页及当前筛选之外的选择 |

三组统计都排除待删除和失效视频。缺少时长的条目会另行标明，不会假定它有确定时长。因此这里的条数可能少于收藏夹总条数。

详情里的「累计至此」按**完整清单顺序**累加，包含当前视频，同样排除待删除和失效视频；它不随筛选缩短。

## 六、导出清单与数据备份

### 导出清单

「导出」生成完整当前整理清单的 CSV，包含未提交的新增、待删除状态及视频资料，保存到 data/exports/。它不会下载视频，也不是只导出已选条目。只需要视频链接时，可在多选后的卡片右键菜单中批量复制链接。

### 数据备份

在「菜单 → 数据」查看软件实际使用的数据目录，通常是程序旁的 data/，目录不可写时可能使用备用位置。退出软件后备份这个目录，可保留标签、草稿、任务存档和偏好。目录内含登录凭证，对外分享程序时不要顺带分享自己的数据。

## 七、外观、快捷键与退出登录

- **主题色**：在菜单账号行点击调色盘按钮设置。
- **跟随系统**：使用 Windows 的强调色。返回软件或系统配色变化后会更新；白天／夜晚仍由顶栏单独切换。
- **导航图标配色**：菜单册子、浏览影片卡及搬运里的小视频卡自动跟随主要色，普通和选中状态同步变化。搬运箱和箭头固定为淡红色，金色配件、白色描边保留原色。
- **白天／夜晚**：在顶栏切换，可与主题色搭配。
- **快捷键**：在「菜单 → 快捷键」查看或修改。按浏览、整理、多选及全局作用域检查冲突，可能同时生效的相同键位会拒绝保存，原设置保留。Esc 保留，Ctrl+C/X/V 为固定卡片剪贴板键，不能分配给其他动作。旧配置已有冲突时会标明，并阻止该冲突动作误执行；输入框保留标准文字编辑。Ctrl+Shift+Z 作为默认重做的备用键，会让位于明确设置的其他功能。
- **退出登录**：在「菜单」的账号区域操作，清除本机保存的登录凭证，下次使用需重新登录。它与关闭软件窗口不同。

## 八、软件内的分步说明

各小板块标题右侧或工具栏角落有一个淡色「?」，点它查看对应功能的说明。页面标题右侧的「?」提供当前页面的完整分步教程。

大肥鱼和说明一起放在教程卡片里。每一步只讲当前高亮的操作，说明卡片跟随对应控件，金色边框标出当前目标。例如关键词、筛选范围、日期各自高亮对应控件；高亮的控件可以直接点击。步数紧跟标题显示，标题下方的细进度条表示阅读进度。

如果功能尚未展开，教程会先单独说明准备操作。例如先指向「开始整理」，等你打开整理模式后，再讲当前编辑工具；不会同时把尚未显示的其他功能混在这一段里。

点 ×、高亮区域之外的空白处或按 Esc 关闭说明，不会清掉原来的输入。窗口缩放、滚动或打开相关面板后，说明会重新定位。

说明均按需打开，不会自动弹出。打开后可用左右方向键翻步，随时关闭、重看。在高亮输入框中编辑时，方向键仍用于移动光标。
